# Textures de fond (calques d'arrière-plan)

Déposer ici les esquisses d'archi utilisées en **fond de site** (calques
discrets derrière le contenu). Style : trait fin clair sur fond sombre,
raccord seamless pour la pierre / le travertin / le bois.

Fichiers attendus :

- `pierre.jpg` — mur en pierre calcaire (esquisse, seamless)
- `travertin.jpg` — dallage pierre / opus (esquisse, seamless)
- `bois.jpg` — poutres / bois (esquisse, seamless)
- `esquisse-maison.png` — mas provençal au trait (filigrane, large)

Une fois les images déposées, elles sont branchées en fond via `css/style.css`.
